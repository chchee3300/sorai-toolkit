# 05: 編輯預設模式

**What to build:** 在 hub 設定頁按某個預設的「編輯」，會打開 Converter 的「編輯預設」模式：載入該預設的類型、格式與參數，佇列裡不需要有檔案；按「儲存預設」覆蓋原本的預設，再回到設定頁；取消則不做任何改動。

**Blocked by:** 04（存成右鍵預設與 hub 預設管理）

**Status:** ready-for-agent

- [ ] 編輯模式明確標示正在編輯哪個預設，按鈕變成「儲存預設」與「取消」
- [ ] 儲存後右鍵選單重寫，預設的 id 不變，所以既有的選單指令仍然有效
- [ ] 編輯模式不影響 Converter 一般佇列的狀態與上次使用的參數
- [ ] E2E：編輯一個內建預設的品質並儲存 → 用 `--sorai-preset=<id>` 轉出的檔案反映新的參數；取消編輯時預設不變
