# 03: 進度視窗的完整行為

**What to build:** 進度視窗具備完整的行為：同時轉 2 個檔案；每列有進度條，可以單獨取消，也可以全部取消；不適用這個預設的檔案標成「已略過：不支援此預設」；只要有失敗，視窗就留著並顯示錯誤；全部成功時發一則系統通知，點了會打開輸出資料夾；轉檔中又有新的啟動，檔案併進同一個視窗排隊；主視窗或系統匣原本就開著時，轉完保持原狀，不結束 app。

**Blocked by:** 01（預設儲存與背景轉檔的最短路徑）

**Status:** done（通知點擊與視窗外觀留給 06 真機驗收）

- [x] 純函式「預設 × 檔案 → 套用或略過」有 cargo test
- [x] 固定同時 2 個 job；單檔取消與全部取消都用 cancel_job，取消後該列的狀態正確
- [x] 有失敗或取消時不自動關閉；只有全部成功（含被略過的檔案）才 3 秒後關閉
- [x] 成功通知點了會用 opener 打開輸出資料夾（通知事件無法自動測試的話，留給 06 真機驗收）
- [x] E2E：混合類型被略過；壞掉的檔案讓視窗留著；同時 2 個（觀察到兩個 job 重疊執行）；第二次啟動併進同一個視窗；主視窗開著時轉完不結束、佇列不受影響
